# Travaux pratiques — M351

Les travaux pratiques du module sont organisés en séries progressives.

## Organisation d'une série

Chaque série comporte deux phases :

1. **Salle** : travail réalisé pendant la séance encadrée ;
2. **Maison** : application, consolidation et transfert des acquis.

## Progression

- Série 1 — Fondamentaux Python
- Série 2 — Représentation et manipulation des données multimodales
- Série 3 — Collecte des données multimodales
- Série 4 — Outils et prétraitement des données multimodales
- Série 5 — Augmentation et équilibrage des données multimodales

Les productions d'une série peuvent être réutilisées dans les séries suivantes.
