# Rapports complémentaires — M351

Ce dossier regroupe les rapports mis à disposition des étudiants pour approfondir les outils, techniques et contraintes rencontrés dans le traitement des données multimodales.

Ces rapports constituent des **documents d'aide à la décision**.

Ils permettent notamment :

- d'identifier les familles d'outils disponibles ;
- de comparer plusieurs solutions ;
- de comprendre leurs contraintes ;
- de justifier un choix technique ;
- de préparer les séances de travaux pratiques.

Ils ne constituent pas un catalogue d'API à mémoriser.
